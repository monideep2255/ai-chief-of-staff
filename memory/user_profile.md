## User profile

The repo owner works in a hybrid technical and product role at Meridian, splitting time between writing code for Atlas and shaping its roadmap with stakeholders.

Working style: prefers concise, direct answers over long explanations. Wants the option surfaced first, then the reasoning, not the other way around. Reads documentation before meetings, so prep docs should assume that context has already been read once.

Current focus: Atlas is the active project. Most sessions in this repo are about Atlas feature work, Atlas planning, or documents that feed into an Atlas stakeholder review.

Communication preference: short sentences, no filler, plain language over jargon. Flag risks early rather than smoothing them over in a status update.

Source quality: PM intuition (read from repeated session patterns, not a stated preference).
