This file is the input the board reads before every session. It is empty on purpose. Fill in your own background, patterns, and principles here, the same way you would brief a real advisor before asking them for hard feedback. The board is only as good as what you tell it about yourself.

Nothing below is real data. Replace every bracketed prompt with your own answer, or delete a section that does not apply to you.
